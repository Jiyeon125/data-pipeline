# 현재 작업 인수인계

최종 갱신: 2026-07-28 KST

## 프로젝트 목적

성과계획서·성과보고서의 프로그램 성과와 열린재정의 예산·집행·결산을 연결해
추가 확인이 필요한 재정사업과 검토 순서를 제시합니다. 실패·낭비·삭감 대상을
자동 판정하지 않습니다.

## 현재 검증된 상태

- 재정 파이프라인: 원천 사업-연도 9,366행을 보존하고 broad/core/ranking
  모집단과 변수별 적격성을 분리했습니다.
- 중기부 성과: 수기 63행을 PDF 원문과 대조해 분석용 성과 마스터와
  프로그램-연도 결합표를 만들었습니다.
- 중기부 분석: 프로그램×연도×회계유형 후보와 복수 시나리오 순위 안정성,
  안정 상위 후보의 세부사업 재정 드릴다운을 구현했습니다.
- 대시보드: 검증된 중기부 산출물만 읽는 Streamlit MVP가 있습니다.
- 3개 부처 확장: 고용노동부 `019`, 보건복지부 `075`, 과기정통부 `162`
  수기 361행의 로컬 PDF 대조를 실행했습니다. 자동 대조는 원문 위치와 사람
  검토 대상을 찾는 용도이며 아직 분석 마스터로 확정하지 않았습니다.

## 바로 다음 작업

1. 기금 집행률의 공식 `지출계획현액` 필드와 단위를 확정합니다.
2. 분모가 확인되지 않은 기금 행을 집행 신호와 순위에서 제한하고 중기부
   후보 영향만 최소 재계산합니다.
3. 3개 부처의 `OCR_REQUIRED` 174행, `AMBIGUOUS` 6행, 값 불일치 19행,
   PDF 값 결측 2행을 사람 또는 승인된 LLM 검수로 정리합니다.
4. 공식 프로그램코드를 확인한 확정행만 성과 마스터로 승격합니다.
5. 그 뒤 3개 부처 순위와 대시보드로 확장합니다.

## 현재 하면 안 되는 것

- 기금 분모 확인 전 기금 집행률을 확정 신호로 발표
- 3개 부처 자동 대조 361행을 확정 성과 데이터로 사용
- 성과를 소속 세부사업의 성과로 배분
- 결측을 0점으로 처리하거나 남은 변수에 가중치 자동 재배분
- 단일 시나리오를 최종 정책 순위로 발표
- 사용자 승인 없이 외부 LLM API 호출
