# 재정사업 점검 우선순위 분석 MVP 최종 보고서

## 결론

현재 MVP는 고용노동부·보건복지부·과학기술정보통신부의 2022~2024년
성과지표와 재정자료를 프로그램×연도×회계유형 단위로 연결하여, 추가 설명이
필요한 후보를 대시보드에서 탐색하는 단계까지 구현되었습니다.

다만 단일 최종 순위는 확정할 수 없습니다. 순위 적격 193행을 네 가지 가중치
시나리오로 비교했을 때 Spearman 순위상관은 0.646~0.917이었지만, 모든
시나리오에 공통으로 포함되는 Top 5와 Top 10은 각각 0행이었습니다. 따라서
현재 결과는 “문제가 있는 사업”의 판정이 아니라, 선택한 관점에 따라 사람이
먼저 살펴볼 후보를 좁히는 도구로 사용해야 합니다.

## 분석 범위와 단위

- 대상: 고용노동부(019), 보건복지부(075), 과학기술정보통신부(162)
- 기간: 2022~2024년
- 주 분석 단위: 부처×프로그램×회계연도
- 순위 비교 단위: 부처×프로그램×회계연도×회계유형
- 세부사업: 프로그램 신호의 원인을 확인하는 드릴다운에만 사용
- 모집단: broad/core/ranking을 목적별로 분리하고 변수별 적격 플래그 적용

성과지표를 특정 세부사업 성과로 귀속하지 않았으며, 본예산·예산현액·지출액을
혼합하지 않았습니다. 결측 신호는 0점으로 대체하거나 남은 변수로 가중치를
재배분하지 않았습니다.

## 핵심 결과

성과·재정 결합표는 347행이고, 이 중 동년도 공동분석 가능 행은 339행입니다.
순위 시나리오에 필요한 변수가 완전한 행은 193행이며, 데이터 검증 우선은
14행, 맥락 전용 후보는 35행, 정보성 행은 110행입니다. 이 상태값은 일부가
서로 다른 목적의 플래그이므로 하나의 구성비처럼 합산해서는 안 됩니다.

네 시나리오는 균등가중, 성과중심, 집행중심, 재정영향 보정입니다. 전체
Spearman 상관이 중간 이상으로 나타나 큰 흐름은 비슷하지만, 개별 후보의
순위 범위 중앙값은 45위이고 최댓값은 124위입니다. 특히 상위권 공통 후보가
없으므로 한 가중치만 선택해 “최종 1위”를 발표하는 것은 현재 근거보다 강한
결론입니다.

부처 내부 비교도 완전히 안정적이지 않습니다. 최소 Spearman 상관은
고용노동부 0.737, 보건복지부 0.451, 과학기술정보통신부 0.668입니다.
따라서 전체 순위와 부처 내부 순위를 함께 보여주고, 시나리오별 순위 범위가
큰 후보는 가중치 의존 후보로 표시하는 현재 대시보드 방식이 타당합니다.

## 데이터 품질

성과 PDF 대조 대상은 361행입니다. 강한 자동 근거가 있는 행은 160행이고,
OCR 필요 174행, 값 불일치 19행, 모호 6행, PDF 누락·수기 존재 2행으로
총 201행은 사람의 원문 확인이 남아 있습니다. 이 201행은 삭제하거나 0점으로
처리하지 않고 `DATA_REVIEW` 상태로 분리했습니다.

분석 마스터의 주요 키 중복은 0건이고, 월별 원본-정규화 금액 차이와 프로그램
금액 대조 차이는 0입니다. M3 방법론 감사에서 프로그램 키에 분야·부문이
빠져 중복처럼 보이던 오류를 수정했으며, 수정 후 감사 전체가 통과했습니다.

## 대시보드 사용법

대시보드는 다음 순서로 사용합니다.

1. 시작 화면에서 결합 현황과 미완료 검수를 확인합니다.
2. 데이터 확인에서 `DATA_REVIEW`와 결합 불가 사유를 먼저 처리합니다.
3. 후보 분석에서 부처·연도·회계유형을 좁히고 프로그램을 선택합니다.
4. 순위 안정성에서 전체 비교와 부처 내부 비교, 시나리오별 순위 범위를 봅니다.
5. 원문 검수에서 수기값과 PDF 근거 페이지를 나란히 확인하고 판정을 저장합니다.

실행 명령은 다음과 같습니다.

```powershell
.venv\Scripts\python.exe -m streamlit run src/fiscal_dashboard/app.py
```

## 해석 한계

- 수기 구조화 성과자료를 사용한 3개 부처 표본이며 전체 정부사업을 대표하지 않습니다.
- 성과지표 유형과 자율평가 의견은 현재 시나리오에 포함되지 않았습니다.
- 201개 성과 원문 대조는 미완료입니다.
- 정답 라벨이나 외부 평가 결과가 없어 외부 타당성은 확인하지 못했습니다.
- 낮은 집행률, 연말집중, 예산 증감은 낭비나 실패가 아니라 설명 필요 신호입니다.
- 예산 환류는 T+1과 T+2를 분리한 연관성 탐색이며 인과관계가 아닙니다.

## 권장 다음 단계

첫째, 대시보드 검수 큐에서 201행을 예산규모와 순위 영향도 순으로 확인합니다.
둘째, 팀이 네 시나리오 중 하나를 고르기보다 공통 후보·순위 범위·부처 내부
순위를 함께 쓰는 발표 원칙을 합의합니다. 셋째, 이 MVP가 실제 검수 시간을
줄이는지 확인한 뒤에만 OCR+LLM 추출을 추가하고, LLM 출력도 같은 검수 큐로
연결합니다. 마지막으로 팀 공유와 피드백을 거쳐야 최종 마일스톤을 완료할 수
있습니다.
