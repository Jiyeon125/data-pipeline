# 전체 PDF 로컬 파싱·선택형 비전 dry-run 결과

## 1. 결론

18쪽 소표본에서 OpenDataLoader가 12/12 지표명과 20/20 같은 행 필드를
복원했지만, 이를 전체 PDF 성능으로 일반화할 수는 없습니다. 24개 전체본에서
후보 766쪽을 다시 검사한 결과, 계획서의 ODL 구조 통과 페이지도 지표명 68.02%,
같은 행 필드 64.53%에 그쳤습니다. 보고서 구조 통과 페이지는 각각 98.44%,
96.25%였으나 자동 확정 기준으로는 아직 부족합니다.

따라서 권장 경로는 다음과 같습니다.

1. 기존 로컬 확정 결과는 재사용합니다.
2. 전체 PDF에서 성과 별첨·성과표 텍스트 신호·기존 발견 페이지를 코드로 고릅니다.
3. OpenDataLoader 구조 검사를 통과한 보고서는 로컬 검증 후보로 유지합니다.
4. 계획서, 회전표, 헤더 손실, 연도·목표·실적·달성률 구조 실패는 비전 후보로 보냅니다.
5. 비전 응답을 수기 골드와 채점하기 전에는 어떤 행도 자동 승인하지 않습니다.

## 2. 입력과 한 행의 기준

- 입력: 4개 부처 × 2022~2024년 × 성과계획서·성과보고서 = 원본 PDF 24개
- 후보 manifest 한 행: `부처 × 회계연도 × 문서유형 × 원본 PDF 페이지`
- 사후 정확도 한 행: `부처 × 프로그램 성과지표 × 회계연도 × 문서유형`
- 원본 PDF는 읽기 전용으로 사용했고 실행 전후 SHA-256이 모두 같았습니다.
- 골드 값은 후보 선정·ODL 파싱·비전 요청 생성에 쓰지 않고 완료 후 채점에만
  사용했습니다.

## 3. 후보 페이지 선정

후보는 다음의 합집합으로 만들었습니다.

- 별첨 표제 기반 프로그램 성과지표 별첨 범위
- 성과계획서의 `성과지표 및 목표치`와 `프로그램목표별 성과지표` 동시 신호
- 성과보고서의 `성과지표·목표·실적·달성률/달성도` 동시 신호
- 기존 무인 파서가 발견한 페이지
- 기존 미해결 큐 페이지

보건복지부 2024 성과계획서는 PDF 텍스트 표제가 없어 목차 OCR, 인쇄쪽-PDF쪽
오프셋, 예상 위치 주변 OCR 순서로 별첨을 찾았습니다. 나머지 23개 문서는 텍스트
표제로 찾았습니다.

초기 넓은 규칙은 1,175쪽을 골라 과도했습니다. 보고서 텍스트 조건을 강화해
766쪽으로 34.8% 줄이면서, 수기 출처 쪽이 실제 PDF와 대체로 맞는 고용노동부·
보건복지부·과기정통부의 ±2쪽 후보 재현율 98.18%와 기존 미발견 행 99.60%를
유지했습니다.

중기부 수기 출처 쪽은 성과지표 표가 아니라 전략 설명, 우수사례, 예산 별첨을
가리키는 사례가 다수였습니다. 그러므로 4개 부처 전체의 정확쪽 재현율 73.57%,
±2쪽 재현율 89.29%는 후보 규칙만의 성능이 아니라 수기 출처 품질의 영향을 함께
받은 진단값입니다.

## 5. 사후 정확도

수기 출처 쪽 ±2 범위에서 지표명을 찾고, 지표명이 복구된 경우에만 목표·실적·
달성률이 같은 표 행에 있는지 평가했습니다.

| 구분 | 지표명 복구 | 같은 행 필드 정확도 |
|---|---:|---:|
| 전체 840 문서-지표 행 | 56.67% (476/840) | 65.71% (803/1,222) |
| ODL 구조 통과 계획서 | 68.02% (117/172) | 64.53% (111/172) |
| ODL 구조 통과 보고서 | 98.44% (315/320) | 96.25% (616/640) |
| 비전 필요로 분류된 연결 행 | 38.46% (10/26) | 27.59% (8/29) |

중기부 126개 문서-지표 행의 수기 쪽이 실제 성과표와 맞지 않아 지표명 복구가
0%였습니다. 중기부를 제외한 지표명 복구율은 66.67%입니다. 이는 중기부를 분석에서
제외하라는 뜻이 아니라, 해당 수기 출처 열을 정답으로 사용하지 말고 지표명·프로그램
식별자로 다시 연결해야 한다는 뜻입니다.

`EXISTING_LOCAL_CONFIRMED` 페이지의 위 정확도는 기존 PyMuPDF 레코드가 아니라 같은
페이지의 ODL 표 행을 채점한 값이므로 기존 로컬 확정 정확도를 재평가한 수치가
아닙니다.

## 6. 비전 요청 패키지와 비용

- 전체 비전 후보: 230요청

- 전체 예상 텍스트 토큰: 28,383
- 전체 예상 출력 토큰: 276,000
- 전체 동기 예상비용: $0.434897
- 전체 Batch 예상비용: $0.217449
- 실제 API 호출: 0회

34건 파일럿은 미해결 큐 4건 전부와 부처×문서유형×첫 실패사유 31개 층을
포함합니다.

| 34건 파일럿 | 예상치 |
|---|---:|
| 이미지 토큰 | 69,242 |
| 텍스트 토큰 | 4,292 |
| 출력 토큰 | 40,800 |
| 동기 비용 | $0.063667 |
| Batch 비용 | $0.031833 |

비용은 `gpt-5.6-luna` 입력 $0.20/1M, 출력 $1.20/1M과 Batch 50% 할인을
적용했습니다. 이미지 `detail=original` 토큰은 `ceil(width/32) ×
ceil(height/32)`로 계산했습니다. 가격과 이미지 입력 방식은 실행일에 공식
[모델 페이지](https://developers.openai.com/api/docs/models/gpt-5.6-luna)와
[이미지 입력 가이드](https://developers.openai.com/api/docs/guides/images-vision)에서
확인했습니다.
