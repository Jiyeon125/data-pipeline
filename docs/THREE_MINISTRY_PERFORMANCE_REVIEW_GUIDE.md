# 3개 부처 성과지표 PDF 원문 검수 안내

## 먼저 결론

고용노동부·보건복지부·과학기술정보통신부 361행을 전부 사람이 검수하지
않습니다.

- 근거 승인: 332행
  - 출처 파일, 페이지, 보고서 원문이 연결되고 지표 대응이 모호하지 않은 행
- 사람 검수 필요: 29행
  - 프로그램·지표 대응 모호 6행
  - 수기값은 있으나 PDF 근거 부족 2행
  - 페이지 또는 텍스트 근거 부족 21행

`근거 승인`은 사람이 읽었다는 뜻이 아닙니다. 출처 추적 가능성을 승인한 것이며,
수기 기준값이나 불일치 값을 자동으로 수정하지 않습니다. 실제 사람 검수로
기록하는 대상은 29행뿐입니다.

작업목록은 다음 파일에 있습니다.

```text
data/interim/llm_harness/human_review_queue.xlsx
```

## 8월 4일 팀 공유용 안내문

아래 문구를 그대로 복사해 전달할 수 있습니다.

```text
[성과지표 PDF 잔여 검수 안내]

1. 저장소 루트에서 대시보드를 실행합니다.
   .\.venv\Scripts\python.exe -m streamlit run src\fiscal_dashboard\app.py

2. '4. 비교·원문 검수' → '원문 검수'를 선택합니다.
   기본 화면에는 사람 판단이 필요한 29행만 표시됩니다.

3. 프로그램·지표명, 계획 목표, 보고 목표, 실적, 공식 달성률과 근거 페이지를
   확인합니다.

4. 검수 결과는 원문과 일치 / 수정 필요 / 현재 문서로 확인 불가 / 보류 중
   하나를 선택합니다.

5. 메모에 파일명, 페이지, 확인한 값과 판정 근거를 적습니다.
   수정 필요라면 정확한 값과 단위도 적습니다.

6. PDF·수기 엑셀·자동 대조 결과는 수정하지 않습니다.
   대시보드 저장값은 별도 감사 CSV에 기록됩니다.
```

## 검수 방법

저장소 루트에서 다음 명령을 실행합니다.

```powershell
.\.venv\Scripts\python.exe -m streamlit run src\fiscal_dashboard\app.py
```

대시보드에서 `4. 비교·원문 검수` → `원문 검수`를 선택합니다. 기본 화면은
29행만 보여줍니다. `근거 승인된 행도 표본 검수 대상으로 보기`를 켜면 나머지
332행도 볼 수 있지만 필수 작업은 아닙니다.

검수 순서는 다음과 같습니다.

1. `AMBIGUOUS` 6행
   - 같은 지표명이 여러 프로그램에 대응합니다.
   - 프로그램명과 표 위치를 함께 확인합니다.
2. `PDF_MISSING_MANUAL_PRESENT` 2행
   - 수기값은 있지만 자동으로 원문 위치를 찾지 못했습니다.
   - 원문에도 없으면 `현재 문서로 확인 불가`로 남깁니다.
3. 근거 부족 `OCR_REQUIRED` 21행
   - 자동 추출 텍스트가 아닌 렌더링된 PDF 페이지를 직접 읽습니다.
   - 페이지가 특정되지 않으면 파일에서 프로그램명과 지표명을 검색합니다.

한 행에서 다음 값을 확인합니다.

1. 지표명과 프로그램 소속
2. 성과계획서의 최초 목표
3. 성과보고서의 최종 목표
4. 성과보고서의 실적
5. 성과보고서의 공식 달성률

별첨6 변경표는 목표 변경의 근거입니다. 실적과 공식 달성률은 성과보고서의
성과표를 우선합니다. 변경표와 성과표가 충돌하면 임의로 선택하지 않습니다.

## 검수 결과와 기록

| 선택값 | 사용 조건 | 분석 처리 |
|---|---|---|
| `원문과 일치` | 프로그램·지표·값이 원문과 일치 | 사람 검수 완료 |
| `수정 필요` | 원문에서 정확한 값이 확인됐지만 수기값 또는 자동값이 틀림 | 메모에 정답 기록, 자동 반영 전까지 미확정 |
| `현재 문서로 확인 불가` | 제공 문서로 값이나 소속을 확정할 수 없음 | 원문 의존 분석에서 제한 |
| `보류` | 추가 파일이나 시간이 필요함 | 미완료 유지 |

메모는 다음 형식을 사용합니다.

```text
[파일·쪽] 파일명 / 분리 PDF 00쪽 / 원본 000쪽
[확인값] 지표명= / 계획목표= / 보고목표= / 실적= / 공식달성률=
[판정근거] 프로그램명과 표 위치 일치 / 별첨6 변경 전·후 확인 / OCR 오독 등
[후속조치] 없음 / 수정 오버레이 필요 / 추가 원문 필요
```

실제 사람이 확인한 결과만 다음 파일에 저장합니다.

```text
data/manual/performance/pdf_reconciliation_manual_confirmations.csv
```

자동 근거 승인을 이 파일에 넣거나 사람 검수로 표시하지 않습니다.

## 관련 파일

| 용도 | 경로 | 수정 여부 |
|---|---|---|
| 성과계획서·성과보고서 원문 | `data/raw/performance_docs/` | 읽기 전용 |
| 부처별 별첨 PDF | `data/raw/performance_docs/appendix/year=연도/ministry_code=코드/` | 읽기 전용 |
| 팀 수기 구조화 원본 | `data/manual/LLM_문서구조화_3개부처_최종제출본.xlsx` | 수정하지 않음 |
| PDF 자동 대조 결과 | `data/processed/performance/pdf_reconciliation/ministry_code=코드/` | 수정하지 않음 |
| 잔여 사람 검수 목록 | `data/interim/llm_harness/human_review_queue.xlsx` | 읽기 전용 작업목록 |
| 사람 검수 저장파일 | `data/manual/performance/pdf_reconciliation_manual_confirmations.csv` | 대시보드가 관리 |

부처코드는 고용노동부 `019`, 보건복지부 `075`, 과학기술정보통신부 `162`입니다.
앞자리 0을 지우지 않습니다.

## 완료 조건

- 29행이 `원문과 일치`, `수정 필요`, `현재 문서로 확인 불가` 중 하나로 정리됨
- 검수자와 파일·페이지·판정 근거가 기록됨
- 수정 필요 행은 정확한 값과 단위가 기록됨
- 같은 `source_indicator_id`가 중복되지 않음
- 8월 4일 팀 공유에서 검수 결과와 후속 결정이 기록됨
