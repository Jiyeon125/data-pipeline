# 선택형 비전 LLM 동기 파일럿 정정 결과

## 결론

34쪽 동기 파일럿의 실행·비용 통제는 성공했지만, 목표연도까지 정확히 귀속된 구조화
필드 정확도는 `16/18(88.89%)`로 사전 기능명세의 확장 기준 `95%`를 통과하지
못했습니다. 추가 API 호출과 230쪽 확장은 중단합니다.

이전 보고서의 `73/258 로컬 자동 대조`를 품질 게이트로 사용한 판단과
`9/9 지표명·7/7 필드` 수치는 철회합니다. 로컬 파싱 실패 페이지를 비전 LLM에
보낸 실험에서 다시 로컬 파서 대조율을 핵심 기준으로 사용한 것은 순환 평가였고,
수기 파일의 PDF 물리 페이지와 문서 인쇄 페이지도 혼용했습니다.

## 실행 범위와 비용

- 모델: `gpt-5.6-luna`
- 요청: 34/34 성공, 반환 레코드 258개
- 성공 응답 토큰: 입력 91,602, 출력 31,506
- 성공 응답 비용: `$0.0561276`
- 절단 응답 재시도와 추적 누락 1건의 보수적 예약 포함: `$0.0750864`
- 승인 상한: `$0.10`
- 재채점 API 호출: 0회
- 입력 원본: 기존 34개 요청과 응답을 그대로 사용

동일한 요청 분포가 유지된다는 단순 비례값은 230쪽 약 `$0.508`, 후보 766쪽 전체
약 `$1.692`입니다. 현재 품질에서는 운영비 견적이나 도입 효과 산정값으로 사용하지
않습니다.

## 올바른 채점 기준

1. `source_pdf_page`는 PDF 파일의 1부터 시작하는 물리 페이지끼리 비교합니다.
2. `printed_page`는 실제 페이지 하단에 인쇄된 번호끼리 비교합니다.
3. `PDF p.494 / 문서 p.486`을 하나의 숫자로 축약하지 않습니다.
4. 수기 성과지표 424개 중 34쪽 입력과 물리 또는 인쇄 좌표가 연결되는 지표만
   페이지 표본의 정답으로 사용합니다.
5. 기대값이 실제 34쪽 입력 이미지에 보이는 필드만 필드 정확도 분모에 넣습니다.
6. 값이 응답 어딘가에 존재하는지와, 해당 값이 올바른 목표연도 레코드에 귀속됐는지를
   분리합니다.
7. 로컬 텍스트·OpenDataLoader 대조율은 보조 진단으로만 유지합니다.

## 보고서 3건 원문 확인

### 고용노동부 2022 보고서

- 수기 파일: PDF p.178 / 인쇄 p.174
- 재조정 근거: PDF p.66
- 실제 입력 PDF p.66 / 인쇄 p.62에 `근로지원인 수혜장애인 비율`, 실적 `1.89`,
  달성률 `113.9`가 모두 보입니다.
- LLM도 정확한 값이 든 레코드를 반환했지만, 같은 지표의 `신규 / -` 중복 레코드
  3개와 함께 반환했고 모든 레코드의 `fiscal_year`를 null로 냈습니다.
- 따라서 값 회수는 2/2이지만 목표연도 구조화는 0/2입니다.

## 해석과 다음 수정

- 계획서 표본은 16개 지표와 16개 목표값이 모두 올바른 연도에 구조화됐습니다.
- 보고서는 표가 페이지 경계에서 이어지고, 동일 지표의 연도 열을 여러 레코드로
  풀면서 연도 null·중복이 생기는 문제가 확인됐습니다.
- 목표연도 LLM 출력 114개 중 수기 지표명과 유사한 것은 53개(46.49%)였지만,
  수기 세트가 34쪽에 등장하는 모든 지표를 포함한다는 보장이 없으므로 이 비율은
  precision이나 정확도로 해석하지 않습니다.
- 다음 API 파일럿 전 로컬 수정 범위는 보고서에 한해 `현재 쪽+다음 쪽` 연결,
  동일 지표 중복 병합, 연도 열 귀속 강제입니다. 계획서 프롬프트와 호출 범위는
  당장 확대하지 않습니다.
