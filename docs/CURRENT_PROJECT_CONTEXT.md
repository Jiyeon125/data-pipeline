## 방법론

보고된 성과 미달을 기준축으로 두고, 집행·반복·예산변화 신호의 동시 관측 여부를 이용해 원문 확인의 우선도와 확인질문을 구분하는 성과 앵커형 질문형 점검등급입니다.

- reported performance: A/B의 기준축
- execution: 우선 확인 필요성 강화
- repetition: 지속성 강화
- budget-performance mismatch: 세부 등급·진단 조정
- data quality: H 판단 보류

A+B는 문제·위험 판정이 아니고 D는 정상·안전 판정이 아닙니다. H는 A~D와 같은 서열이 아니라 데이터 보완 업무입니다. 생산 등급은 LLM 결과로 결정하지 않습니다.
