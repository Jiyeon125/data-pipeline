# LLM 파일럿 비용·도입 순편익

## 결론

중기부 가린 골드셋 파일럿은 **이미 위치가 확인된 성과지표의 값 구조화 가능성**을
확인했습니다. v2는 지표를 한 요청에 하나씩 보내 34/34가 사후복구 없이 최초 strict
검증을 통과했습니다. 이후 로컬 PDF 계층·연도 추출로 동일 지표명 원문 충돌 2행과
다년도 표 1행을 바로잡았지만, 이 새 입력의 API 정확도와 PDF 전체 무인 탐색 성능은
아직 검증하지 않았습니다.

공공업무에서는 `순익`보다 다음 용어를 사용합니다.

```text
반복 순편익 = 품질보정 검토시간 절감액 - 유지관리비 - API비
첫 회 순편익 = 반복 순편익 - 1회성 구축비
```

사용했습니다. 숫자 필드는 `50.4`와 원문 `50.4(%)`처럼 값은 같고 단위 표기만 다른
경우를 의미동등으로 비교했습니다.

v1·v2 공통 19지표에서 사후복구를 제외한 종단 strict 결과는 v1 16/19에서

각각 13/16에서 15/16으로 개선됐습니다. 다만 요청 묶음이 바뀌며 전체 34지표 중
15지표가 교체됐으므로 전체 34행을 직접 전후 비교한 결과로 표현하지 않습니다.

v2 실측비용을 단순 비례하면 4개 부처 424지표 약 `$0.215`(약 301원), 연간
141지표 약 `$0.071`(약 100원)입니다. 이는 이미 위치가 확인된 지표의 구조화 비용이며
PDF 전체 탐색·OCR·재처리 비용은 포함하지 않습니다.

## v3 공통 원문 보정 로직 — API 미호출 재적용

v2의 원시 LLM 결과 34건에 코드만 재적용했습니다. 원시 출력은 보존하고
`resolved_*` 필드만 운영값으로 분리했습니다.

| 처리 | 결과 |
|---|---:|
| 변경표의 변경 전 목표로 교정 | 2행 |
| 로컬 PDF 후보가 요청 원문에 그대로 있을 때 결측 보완 | 2행·4필드 |
| 동일 원문이 여러 프로그램에 연결된 충돌 차단 | 2행 |
| 변경 없음 | 28행 |
| 충돌 제외 사용 가능 | 32/34, `94.1%` |

사용 가능 32행의 사후 오프라인 평가에서 지표명 32/32, 단위 32/32, 계획목표
32/32, 정답이 있는 실적 27/27, 공식 달성률 27/27이 일치했습니다. 이는 새 모델
호출의 정확도가 아니라 **기존 LLM 출력에 공통 원문 가드를 결합한 운영 정확도**입니다.
수기 정답지는 보정·차단·재시도 판단에 사용하지 않고 결과 평가에만 사용했습니다.

34건 v3 파일럿은 API 호출 없이 준비했습니다. 아래 PDF 문맥 보강 후 Luna Batch
예상비용은 `$0.0149474`, 최대 출력 기준 비용 게이트는 `$0.0424874`이며 설정은
`api_execution_allowed=false`로 잠겨 있습니다.

### v3 PDF 프로그램·연도 문맥 보강

이후 PDF 표의 프로그램목표 번호·프로그램명과 따옴표가 붙은 연도 머리글을 로컬로
추출하도록 개선했습니다. 중복 지표는 이름만으로 첫 출현을 고르지 않고
`지표명 + 프로그램목표 번호`로 구분합니다.

- 2022년 Ⅱ-1: 별첨 6쪽, `8.13 / 8.28 / 101.8%`
- 2022년 Ⅲ-1: 별첨 7쪽, `16.6 / 17.7 / 106.6%`
- 2024년 Ⅲ-1: `'22년|'23년|'24년` 중 `'24년`,
  `233,033 / 214,917 / 92.2%`

중기부 63행 재대조에서 행 수와 원본 해시를 보존했고 `AMBIGUOUS`는 2행에서
0행으로 줄었습니다. 새 v3 요청 34건의 원문 지문 충돌도 0건이며 수기 정답 필드의
요청 누출은 0건입니다. 이 결과는 입력 문맥 개선 검증이며, 새 API 응답 정확도는 아직
측정하지 않았습니다.

## v1 실측 결과

| 항목 | 결과 |
|---|---:|
| 모델 | GPT-5.6 Luna, reasoning low, Batch |
| 요청 | 12건 |
| 지표 | 34건 |
| 입력 토큰 | 16,790 |
| 출력 토큰 | 11,090 |
| 총 토큰 | 27,880 |
| 토큰 기준 Batch 비용 추정 | `$0.008333` |
| 유효 요청 | 11/12, `91.7%` |
| 엄격 검증 레코드 | 23/34, `67.6%` |
| 로컬 복구 포함 레코드 | 32/34, `94.1%` |
| 중복 원문 충돌 제외 레코드 | 30/34, `88.2%` |
| API 실패 | 0건 |
| 남은 재시도 | 1요청·2지표 |

검증 실패 원인은 다음과 같습니다.

- 잘린 JSON 앞부분의 완결 레코드 4개를 독립 검증해 복구했습니다.
- 생략 부호가 들어간 인용 5개는 해당 인용만 버리고, 각 필드가 같은 레코드 원문에
  존재하며 다른 정확 인용이 남은 경우에만 복구했습니다.
- 근거가 확인되지 않는 필드는 `null`로 낮췄고 모든 복구행은 사람 검수 대기입니다.
- 남은 2지표만 최소 재시도 대상으로 분리했습니다.
- 같은 원문이 서로 다른 프로그램 두 행에 연결된 충돌 1그룹은 자동 사용에서
  제외했습니다. PDF 확인 결과 올바른 값은 보고서 별첨 분리 PDF 7쪽의
  `목표 16.6, 실적 17.7, 달성률 106.6%`이므로 상류 PDF 매칭 수정이 필요합니다.

## v1 필드 품질

정확도는 **유효 응답이 있고 수기 정답도 존재하는 행**에서만 계산합니다. 수기값이
비어 있는데 LLM이 원문에서 값을 찾은 경우를 오답으로 세지 않습니다.

| 필드 | 비교 | 정확 | 조건부 정확도 | 전체 선택행 기준 종단 회수율 |
|---|---:|---:|---:|---:|
| 지표명 | 30 | 28 | 93.3% | 87.5% |
| 단위 | 30 | 28 | 93.3% | 87.5% |
| 계획 목표 | 30 | 25 | 83.3% | 78.1% |
| 실적 | 18 | 16 | 88.9% | 84.2% |
| 공식 달성률 | 18 | 18 | 100.0% | 94.7% |

표는 중복 원문 충돌 2행을 제외한 결과입니다. 복구로 커버리지는 증가했지만 계획
목표·실적의 조건부 정확도는 낮아졌으므로, 커버리지 개선을 정확도 개선으로 표현하지
않습니다. 수기 실적·달성률 결측에서 원문 근거가 있는 값도 찾았지만 사람 검수 전에는
분석값으로 승격하지 않습니다.

## API 비용 환산

파일럿 지표당 실측 비용과 유효 요청률을 이용해 재시도 배수 `1.09`를 적용했습니다.

| 범위 | 재시도 보정 API 비용 | 1,400원/$ 가정 |
|---|---:|---:|
| 파일럿 34지표 | 약 `$0.0091` | 약 13원 |
| 남은 2지표 재시도 | 기대 약 `$0.00045`, 상한 약 `$0.00126` | 약 1.8원 이하 |
| 4개 부처 3개년 424지표 | 약 `$0.1134` | 약 159원 |
| 4개 부처 연간 약 141지표 | 약 `$0.0378` | 약 53원 |

환율 `1,400원/$`는 비교 편의를 위한 가정입니다. 실제 청구액·적용 환율과 대조하기
전에는 확정 비용으로 표현하지 않습니다.

## 순편익 민감도

중복 원문 충돌을 제외한 순편익 적용 커버리지 `88.2%`만큼만 검토시간이 절감되고,
나머지는 기존 수작업을 유지한다고 가정했습니다.

| 시나리오 | 수기/보조 검토시간 | 시간당 원가 | 유지관리 | 424지표 반복 순편익 | 연간 141지표 반복 순편익 |
|---|---:|---:|---:|---:|---:|
| 보수 | 3분 / 2분 | 3만원 | 4시간 | 약 6.7만원 | 약 -5.8만원 |
| 기준 | 5분 / 1.5분 | 5만원 | 4시간 | 약 89.1만원 | 약 16.4만원 |
| 확대 | 10분 / 1분 | 7만원 | 4시간 | 약 364.8만원 | 약 102.9만원 |

초기 구축 `40시간`을 추가하면 424지표 확대 시나리오만 첫 회 순편익이 약 `84.8만원`
양수이고, 기준 시나리오는 약 `-110.9만원`입니다. 즉 보통 가정에서는 한 번에
구축비를 회수하기 어렵고 전 부처 확대·다년도 재사용이 필요합니다.

기준 시나리오의 손익분기 수기 검토시간은 다음과 같습니다.

- 424지표 재처리: 지표당 약 `2.14분`
- 연간 약 141지표: 지표당 약 `3.43분`

## 발표용 권장 문장

> 중기부 파일럿의 LLM API 비용은 34지표에 1센트 미만이었고, 4개 부처 3개년
> 424지표로 확대해도 재시도 포함 약 0.11달러로 추정됩니다. 로컬 복구로 응답
> 처리 커버리지는 94.1%까지 높였지만 중복 원문 충돌을 제외한 적용 커버리지는
> 88.2%입니다. 도입 경제성은 모델 가격보다 사람 검수시간과 유지관리비에
> 좌우됩니다. 기준 가정에서 반복 순편익은 약 89.1만원이지만 초기
> 구축비까지 포함한 첫 회는 적자이므로, 커버리지 개선과 전 부처 재사용을 통해
> 고정비를 분산하는 것이 핵심입니다.
