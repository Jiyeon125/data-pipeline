# 멘토링 원칙 현재 반영 재점검

최종 갱신: 2026-08-04 (3차 멘토링·시나리오 본편 제거 반영)

상세 3차 세션: `docs/MENTORING_SESSION_3_2026-08-04.md`  
가이드 본문 갱신: `docs/MENTORING_GUIDE.md` §32

## 결론

현재 프로젝트는 회계유형별 집행률, 분석 제외, 프로그램 성과와 세부사업의
계층 분리, T+1·T+2 코호트 분리, **유형별 점검 대기열 본편**,
**신호점수·예산규모 분리**, **가중 시나리오 4종 본편 UI 제거**까지 반영했습니다.

다만 다음 자료·설계가 없으므로 “멘토링 전체 반영 완료”라고 할 수 없습니다.

- 사업별 기대 성과발현 시차
- 의무지출과 법적 조정가능성
- 성과지표 INPUT·PROCESS·OUTPUT·OUTCOME 유형
- 목·비목 구성과 사업목적 외 지출
- 융자 공급액·회수액·순재정부담 (**3차: 별도 축 필수**)
- 공식 평가결과와 예산변화 사유
- 데분 Q4(검수 신뢰도 처리)·Q6(라벨 없는 타당성 검증) 결정

## 본편 산출 규칙 (2026-08-04)

기본 점검강도 순서:

1. `DATA_FIRST`
2. `REPEATED_OR_MULTIPLE`
3. `STRONG_SINGLE` (성과미달 단독 제외)
4. `SINGLE_REVIEW`
5. `CONTEXT_REVIEW`
6. `MONITOR`

같은 강도 안:

1. 반복 신호 종류 수
2. 독립 신호군 수
3. 근거상태
4. **`signal_score`** (성과·집행·불일치 평균, 규모 제외)
5. 본예산 (동률 정리만)
6. 안정 식별자

본예산·`fiscal_impact`는 문제점수가 아니다.
가중 시나리오 평균순위는 본편 순서에 사용하지 않는다.

## 해석 한계

- 융자·기금은 아직 별도 영향도 축이 없다.
- 성과미달을 “진입만”으로 완전 분리한 구조는 아니다 (`signal_score`에 강도 포함).
- 데분 Q4·Q6는 3차에서 다루지 않았다.
