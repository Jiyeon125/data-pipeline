# 멘토링 원칙 현재 반영 재점검

## 결론

현재 프로젝트는 회계유형별 집행률, 분석 제외, 프로그램 성과와 세부사업의
계층 분리, T+1·T+2 코호트 분리까지는 반영했습니다. 이번 개편으로 기본
대시보드와 점검업무 순서에서도 가중합을 제거했습니다.

다만 다음 자료가 없으므로 “멘토링 전체 반영 완료”라고 할 수는 없습니다.

- 사업별 기대 성과발현 시차
- 의무지출과 법적 조정가능성
- 성과지표 INPUT·PROCESS·OUTPUT·OUTCOME 유형
- 목·비목 구성과 사업목적 외 지출
- 융자 공급액·회수액·순재정부담
- 공식 평가결과와 예산변화 사유

## 현재 반영 상태

| 멘토링 원칙 | 현재 상태 | 실제 반영 | 남은 조치 |
|---|---|---|---|
| 자동 실패·삭감 판정 금지 | 완료 | 점검강도·다음 행동만 생성 | 표현 유지 |
| 프로그램 성과와 세부사업 분리 | 완료 | 프로그램 성과는 상위 맥락, 세부사업은 자체 재정신호 드릴다운 | 사례 원문 검수 |
| 일반·특별·기금 분리 | 완료 | 회계유형별 행과 분모 유지, 기금 경고·필터 제공 | 기금 내부 사례 검수 |
| 내부거래·전출·원금상환·여유자금 제외 | 완료 | 세부사업 대기열 3,286행의 제외범주 누출 0 | 규칙 유지 |

| 반복 저집행·연말집중 분리 | 완료 | 반복 신호 종류를 독립 보존하고 점검강도에 사용 | 실제 지연사유 확인 |
| 예산구조 확인 | 부분 | 세부사업 수·Top1·Top3·HHI·재배분 맥락 | 목·비목과 목적 외 지출 필요 |
| 실질화 | 미반영 | 명목값임을 유지 | GDP 디플레이터 선택·기준연도 결정 |
| 가중합보다 설명 가능한 유형화 우선 | 완료 | 여섯 점검강도와 다음 행동으로 기본 업무순서 구성 | 상위·반례 사례 검수 |
| 가중치 민감도 | 완료(보조) | 기존 네 시나리오는 고급 민감도에만 보존 | 기본 순위로 승격 금지 |
| 데이터 신뢰도와 정책 신호 분리 | 완료 | DATA_FIRST와 evidence_status 분리 | 15행 데이터 작업 해결 |

## 이번 개편의 산출 규칙

기본 점검강도는 다음 순서입니다.

1. `DATA_FIRST`
2. `REPEATED_OR_MULTIPLE`
3. `STRONG_SINGLE`
4. `SINGLE_REVIEW`
5. `CONTEXT_REVIEW`
6. `MONITOR`

같은 강도 안에서는 다음 순서만 사용합니다.

1. 반복 신호 종류 수
2. 독립 신호군 수
3. 근거상태
4. 본예산
5. 안정 식별자

본예산은 문제점수가 아니라 같은 점검강도 안에서 업무 영향도를 정리하는
보조값입니다. 가중 시나리오 평균순위는 이 순서에 사용하지 않습니다.

516,712,368,600,000원이며 프로그램별 합계 차이는 0원입니다.

## 해석 제한

- `MONITOR`는 안전 또는 정상 판정이 아닙니다.
- 프로그램 성과미달은 소속 세부사업의 성과미달을 의미하지 않습니다.
- 기금은 제외하지 않지만 일반회계와 같은 집행률 척도로 직접 서열화하지
  않습니다.
- T+1·T+2 부분 연결값은 화면 맥락으로만 표시하고 강한 신호 판정에는
  사용하지 않습니다.
- 코호트 기준 세부사업 미연결 3행은 프로그램 환류 집계에서 제외하되
  누락 수를 품질요약에 남깁니다.
- 기존 가중치 결과는 재현·민감도 확인용이며 기본 업무순서가 아닙니다.
