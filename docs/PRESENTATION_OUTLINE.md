# 재정사업 질문형 점검등급 대시보드 발표자료 개요

## 발표 전제

- 기본 분량: 12분, 13장
- 청중: 경진대회 심사위원과 재정·성과관리 실무자
- 한 문장 메시지: **사업을 자동 평가하는 도구가 아니라, 긴 원문에서 먼저 확인할 프로그램과 질문을 줄여주는 의사결정 보조도구**
- 표현 금지: 실패·비효율 사업, 구조조정·감액 대상, 정확도·적중률

## 12번 슬라이드에 반드시 넣을 한계

> 블라인드 쌍대비교 검토표를 설계하고 연구자 1인의 예비 사용성 점검을 수행하였으나, 제출 일정 내 독립 검토자를 추가 확보하지 못해 검토자 간 일치도와 모델-사람 판단 부합도는 산출하지 않았다. 해당 검증은 후속 과제로 남겼다.
