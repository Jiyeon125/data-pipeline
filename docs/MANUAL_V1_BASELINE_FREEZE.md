# manual-v1 기준선 동결

동결일: 2026-07-31

## 동결 목적

LLM 모듈을 선택 부착하기 전에 4개 부처 수기 성과자료 기반 분석을 재현 가능한
기준선으로 고정합니다. 이후 LLM 결과는 이 기준선을 덮어쓰지 않고 별도
비교·검수·승격 경로를 사용합니다.

## 동결 범위

- 부처: `019`, `075`, `102`, `162`
- 연도: 2022~2024년
- 성과지표: 424행
- 프로그램-연도-회계유형 후보: 412행
- 세부사업·원문검수 통합 업무대기열: 3,301행
- 주 후속예산: 단일 회계 프로그램 전체 본예산
- 보조 후속예산: 연속 관측 세부사업 소계
- 기본 업무순서: 비가중 신호 유형
- 가중 시나리오: 고급 민감도 분석에만 사용

## 합격 조건

- 후보 412행과 `candidate_id`를 보존합니다.
- 프로그램 전체예산과 분석부분합계를 다른 필드로 보존합니다.
- T+1과 T+2를 섞지 않습니다.
- 기금과 일반·특별회계를 직접 서열화하지 않습니다.
- 프로그램 성과를 세부사업에 귀속하지 않습니다.
- 원본 PDF·수기 엑셀·API 응답·인증정보를 패키지에 넣지 않습니다.
- 패키지의 모든 파일은 `MANIFEST.json`의 SHA-256과 일치해야 합니다.

## LLM 승격 경계

LLM 결과는 다음 조건을 모두 통과할 때만 별도 분석 입력으로 승격합니다.

1. 엄격한 JSON 스키마를 통과합니다.
2. 문서·페이지·근거문장이 존재합니다.
3. 확인되지 않은 값은 `null`입니다.
4. 기본키와 금액·단위 규칙을 통과합니다.
5. 골드셋 또는 사람 검수에서 승인됩니다.
6. 수기 기준선과 차이를 추적할 수 있습니다.

API 키가 없거나 LLM 검증에 실패하면 `manual-v1`을 계속 사용합니다.
