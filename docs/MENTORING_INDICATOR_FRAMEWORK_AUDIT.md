# 멘토링 근거 기반 점검지표 체계 재검토

## 1. 결론

현재의 네 구성요소 가중합을 기본 점검방식으로 유지할 근거는 충분하지 않다.
멘토링 지침은 통합점수를 허용하지만 필수로 요구하지는 않으며, 오히려 다음을
반복해서 요구한다.

- 동년도 점검과 T+1·T+2 환류를 한 점수에 섞지 않는다.
- 재정수단·회계유형·사업유형이 다른 사업을 같은 기준으로 줄 세우지 않는다.
- 복수 성과지표를 평균 하나로 축약하지 않는다.
- 데이터 신뢰도를 정책성과와 혼합하지 않는다.
- 성과 양호·예산 감소와 성과 미달·예산 증가를 대칭 점수로 합치지 않는다.
- 사업목적과 성과 발현 시차를 먼저 확인한다.

따라서 다음 개편이 타당하다.

```text
가중합 중심 순위
→ 사업성격별 비교집단
→ 유형별 독립 신호
→ 반복성·근거강도·데이터상태 표시
→ 전문가가 점검할 업무대기열
```

가중합은 기본 화면에서 제거하고, 나중에 전문가가 명시적으로 선택할 때만
민감도 분석으로 남기는 방안이 가장 방어 가능하다.

## 3. 현재 네 구성요소와 멘토링 지침의 차이

| 현재 구성요소 | 현재 산식 | 멘토링 기준 대조 | 판정 |
|---|---|---|---|
| 성과격차 | 미달지표 수 ÷ 비교가능 지표 수 | 중앙값·최저·반복미달·지표유형·목표변경 등이 누락 | 부분 |
| 집행관리 | 현재 집행심각도·반복 저집행·반복 연말집중의 최댓값 | 사업별 집행지연 사유와 다년도 사업 특성을 반영하지 않음 | 부분 |
| 성과·예산 불일치 | 성과미달×급증과 성과양호×급감의 최댓값 | 두 방향을 대칭 점수로 합치지 말라는 지침과 충돌 | 수정 필요 |
| 재정영향 | 연도별 본예산 백분위 | 멘토링의 네 번째 유형은 예산규모가 아니라 예산구조 검토 | 역할 변경 |

현재 `fiscal_impact`는 점검위험을 뜻하지 않는다. 큰 사업을 먼저 보면 검토
파급효과가 크다는 업무 우선순서 또는 동순위 보조값으로만 쓰는 것이 타당하다.

멘토링의 네 번째 유형인 `BUDGET_STRUCTURE_REVIEW`는 다음을 뜻한다.

- 목·비목 구성이 사업목적과 맞는지
- 사업목적 외 다른 성격의 지출이 과도하게 포함됐는지
- 융자사업에서 융자금 이외 예산이 과도한지

현재 프로그램 집중도나 회계 맥락만으로 이 개념을 완전히 대체할 수 없다.

## 4. 먼저 분리해야 할 사업 맥락

아래 값은 점수가 아니라 비교집단 또는 해석조건이다.

| 맥락 | 필요한 값 | 이유 | 현재 상태 |
|---|---|---|---|
| 재정수단 | 직접·보조·출연·융자·보증·출자·R&D·시설·정보화·운영 | 돈의 의미와 성과 발현구조가 다름 | 규칙 후보만 존재, VERIFIED 0 |
| 회계유형 | 일반·특별·기금·책임운영기관 | 집행률 분모와 잔액 활용구조가 다름 | 사용 가능 |
| 사업유형 | 즉시 서비스·이전지출·하위기관 집행·다년도 R&D·시설·정보화·정책금융 등 | 인풋에서 아웃풋까지 필요한 시간이 다름 | 부분 후보만 존재 |
| 성과발현 시차 | 동년도·T+1·T+2·장기·미확인 | 늦게 성과가 나오는 사업을 즉시성과 사업과 비교하지 않기 위함 | T+1·T+2 재정 코호트만 존재 |
| 의무지출 | 의무 여부·법적근거·조정가능성 | 성과와 무관하게 예산이 유지될 수 있음 | 미구축 |
| 사업 생애주기 | 신규·계속·종료·이관·통합·분할·단계전환 | 일반 증감률과 반복성 해석이 달라짐 | 관계 후보 존재, 공식확정 제한 |
| 사업규모 | 본예산 규모구간·비교집단 내 백분위 | 규모효과와 소액분모 왜곡 통제 | 사용 가능 |
| 데이터 상태 | 분모·매칭·원문·금액유형·수기검수 상태 | 정책점검보다 데이터검증이 먼저일 수 있음 | 사용 가능 |

성과발현 시차를 운영 가능한 값으로 만들려면 다음 후보 필드가 필요하다.

```text
delivery_pattern:
  IMMEDIATE_SERVICE
  ANNUAL_TRANSFER
  DOWNSTREAM_EXECUTION
  MULTIYEAR_RND
  MULTIYEAR_INFRASTRUCTURE
  FINANCIAL_SUPPORT
  UNKNOWN

expected_outcome_lag:
  T
  T_PLUS_1
  T_PLUS_2
  LONGER
  UNKNOWN

lag_basis
lag_review_status
```

이는 멘토링의 다년도 R&D, 하위기관 집행시차, T+1·T+2 분석 지침을
실제 비교집단에 반영하기 위한 설계 후보이며, 공식 근거 없이 자동 확정하지
않는다.

## 5. 독립적으로 보여줄 지표 후보

### 5.1 데이터 적격성과 근거

정책 신호와 합치지 않는다.

- 프로그램·세부사업 코드 확인 여부
- 회계유형과 집행률 분모 확인 여부
- 본예산·현액·지출·결산 금액유형 확인 여부
- 성과·재정 매칭상태
- 원문 페이지와 사람 검수상태
- 구조적 결측 여부와 사유
- 사업계보 검수상태
- 재정수단·사업유형 분류상태
- `manual_review_required`
- `data_confidence_score`

### 5.2 성과 프로필

한 숫자로 합치지 않고 분포와 품질을 함께 제시한다.

- 성과지표 수
- 비교가능 지표 수와 커버리지
- 중앙값 달성률
- 평균 달성률
- 미달지표 비율
- 최저 달성률
- 반복미달 횟수와 반복미달률
- INPUT·PROCESS·OUTPUT·OUTCOME 지표 비율
- 목표치 변경 지표 비율과 변경 방향
- 과대달성 지표 비율
- 공식 산식 검토 필요 지표 수
- 지표방향 미확인 수

도전성·정책적 중요도는 공식 평가의견, 과거 추세, 외부 벤치마크가 없으면
점수화하지 않는다.

### 5.3 집행 프로필

- 적정 분모가 확인된 집행률
- 집행률 80% 미만
- 집행률 80~90%
- 같은 비교집단 하위 10%·20%
- 반복 저집행 횟수와 유효연도 대비 비율
- 4분기 집행비중
- 12월 단월 집행비중
- 반복 연말집중 횟수
- 누계 감소 횟수
- 이월액·이월률
- 불용액·불용률
- 집행률 100% 초과와 분모 검토상태
- 집행지연 사유코드와 원문 근거

집행지연 사유는 최소한 다년도 R&D, 조달·계약, 인허가, 계획변경,
하위기관 집행시차, 연말 일괄지급, 수요감소, 사업종료를 구분한다.

### 5.4 예산 환류 프로필

동년도, T+1, T+2를 별도 열과 별도 화면으로 유지한다.

- 동년도 본예산·현액·지출·결산
- T+1 명목 예산증감률
- T+2 명목 예산증감률
- T+1 실질 예산증감률
- T+2 실질 예산증감률
- 프로그램 총액 변화
- 프로그램 내부 세부사업 재배분
- 성과 미달 + 후속 예산 증가
- 성과 양호 + 후속 예산 감소
- 집행 설명 필요 + 후속 예산 증가·감소
- 예산변화 공식 사유와 검수상태

`성과 미달 + 예산 증가`는 강한 확인 신호다. `성과 양호 + 예산 감소`는
사업 완료·수요 감소·효율화·단계전환일 수 있으므로 구조변경 맥락으로만
표시한다.

### 5.5 예산구조 프로필

현재 데이터로 가능한 값:

- 프로그램 공식 총예산
- 분석대상 세부사업 예산과 범위비중
- 세부사업 수
- 상위 1개·3개 세부사업 예산비중
- HHI와 세부사업 수 보정 HHI
- HHI 전년 대비 변화
- 세부사업별 예산증감과 내부 재배분
- 단일 세부사업 프로그램 여부

추가 원자료가 필요한 값:

- 목·비목 구성
- 사업목적 외 지출 비중
- 융자금·운영비·기타 부대비용 구성
- 보조·출연·융자·보증·출자의 수단별 적정 규모지표
- 융자 공급액·회수액·순재정부담

### 5.6 외부 평가와 정성근거

점수 정답으로 사용하지 않는다.

- 평가제도
- 평가연도와 평가대상단위
- 평가결과·등급
- 주요 지적사항
- 개선계획
- 사업 필요성
- 전달체계와 수혜자
- 유사·중복 가능성
- 예산변화 공식 사유
- 근거 문서와 페이지

- 미달지표 비율
- 현재 집행률과 80%·90% 구간
- 비교집단 상대 집행 신호
- 반복 저집행
- 4분기·12월 연말집중과 반복
- 누계 감소
- 이월·불용
- 예산 급증·급감
- 프로그램 집중도, Top1·Top3, HHI
- 본예산 규모와 비교집단 백분위
- 회계유형
- 데이터 신뢰도와 검수상태
- 사업 관계 후보
- T+1·T+2 재정 코호트

### 일부만 가능

- 성과달성률 분포: 공식 달성률은 있으나 유형·측정산식·반복미달 집계 미구현
- 재정수단·사업유형 비교: 3,610개 분류가 모두
  `RULE_CANDIDATE` 또는 `MANUAL_REVIEW`이고 `VERIFIED`는 0
- 성과발현 시차: T+1·T+2 재정표는 있지만 사업별 기대시차 분류가 없음
- 목표치 변경: 중기부 일부에만 PDF 변경근거가 있음

### 추가 자료 또는 사람 검수가 필요

- 의무지출과 법적 조정가능성
- 사업별 성과발현 시차
- 집행지연 실제 사유
- INPUT·PROCESS·OUTPUT·OUTCOME 유형
- 성과지표 도전성
- 목·비목 기반 예산구조
- 융자 공급액·회수액·순재정부담
- 공식 평가결과와 개선계획
- 예산변화 공식 사유

## 7. 권장 화면과 업무순서

기본 화면은 총점 대신 다음을 한 행에 병렬 표시한다.

```text
사업 맥락
성과 신호
집행 신호
T+1 환류 신호
T+2 환류 신호
예산구조 신호
반복성
데이터 신뢰도
원문 검수상태
본예산 규모
```

업무대기열은 가중합이 아니라 다음 규칙으로 구성할 수 있다.

1. 데이터 차단 문제를 먼저 분리
2. 강한 독립 신호가 있는 사업
3. 같은 신호가 여러 연도 반복된 사업
4. 서로 다른 신호가 동시에 나타난 사업
5. 공식 근거 또는 원문 확인이 필요한 사업
6. 같은 조건에서는 본예산 규모가 큰 사업

이 순서는 정책효과성 순위가 아니라 검토업무 순서다. 가중치를 자유롭게
조정하는 기능은 기본 결과가 아니라 선택형 민감도 도구로만 남긴다.

## 8. 다음 설계 결정

코드를 수정하기 전에 다음을 확정해야 한다.

1. 현재 네 가중합과 평균 시나리오 순위를 기본 화면에서 제거할지
2. 성과·집행·환류·예산구조를 독립 탭 또는 독립 열로 표시할지
3. 사업성격 분류를 어느 수준까지 사람 검수할지
4. 사업별 기대 성과시차를 수기로 입력할 최소 필드와 검수범위
5. 가중치 분석을 완전히 폐기할지, 전문가 선택형 민감도로만 보존할지
