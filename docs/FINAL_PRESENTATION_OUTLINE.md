# 최종 발표 개요 · 13장

모든 수치는 [PRESENTATION_NUMBERS_SINGLE_SOURCE.md](PRESENTATION_NUMBERS_SINGLE_SOURCE.md)를 따릅니다.

## 1. 문제 정의

77개 프로그램의 원문을 같은 깊이로 읽지 않고, 구조화 신호에 따라 확인 순서와 질문을 나눕니다.

## 2. 데이터와 분석 단위

부처 × 프로그램 × 회계연도 236행, 2024년 77개를 기준으로 설명합니다.
분석 범위는 2022~2024년이며 2025년도 성과계획서는 차년도 변화 확인용 참고자료로 분리합니다. 상세 기준은 [CURRENT_PROJECT_CONTEXT.md](CURRENT_PROJECT_CONTEXT.md)를 따릅니다.

## 3. 대시보드 업무흐름

개요 → 점검 대기열 → 프로그램 상세 → 분석·검증. PDF는 별도 검수자 모드입니다.

## 4. 각 신호는 같은 역할을 하지 않는다

성과는 A/B 진입 앵커, 집행은 우선도 강화, 반복은 지속성 강화, 예산괴리는 세부등급·진단 조정, 품질은 H 보류입니다.

## 5. 질문형 점검등급

A+B 우선 확인, C 맥락 확인, H 데이터 보완, D 모니터링입니다. 위험·성과·정책효과 등급이 아닙니다.

## 6. 2024년 대기열

A4 B2 C35 H8 D28을 표시하고 H를 A~D 서열과 분리합니다.

## 7. 규칙을 만들고 끝내지 않았다

A~D 유지율 93.78%~100.00%, A+B Jaccard 0.8824~1.0000, 5/6 안정, A↔D 0, 신호 제거 결과, 외부검증 8/2/2를 표시합니다.

## 8. 안정 핵심군과 경계 사례

안정 핵심군 5개, 경계 사례 소록도병원 1개를 보조 설명으로만 사용합니다.

## 9. 검토범위 압축

77개 → 6개 프로그램, 1,080개 → 74개 원문 단위. 안정 핵심군은 70개, 경계군은 4개 원문 단위입니다.

## 10. 예산영향은 별도 축

A+B 본예산 3.91%, D 81.84%를 함께 보여주고 규모와 확인 우선도를 분리합니다.

## 11. 다음 연도 방향성

A+B 동일 신호 14/24, A+B 유지 8/24, C→A/B 15/53, D→A/B 2/59입니다. 예측력이 아니라 방향적 연관성입니다.

## 12. 외부검증과 사람 검토

SUPPORTED 8, CONTRADICTED 2, INSUFFICIENT 2와 건강보험제도 운영 누락 사례를 제시합니다. 독립 검토자 간 일치도는 후속 과제입니다.

## 13. 한계와 활용

성과 앵커형 규칙, 법률·제도·재원구조 위험 미포함, peer 적용범위 부족, 독립 사람검증 미완료, 다음 연도 분석의 비예측적 성격을 밝히고 원문 확인 업무 분할 도구로 제안합니다.
