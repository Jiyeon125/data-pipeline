# 외부검증·블라인드 검토 통합 판정 기준

## 로직 수정 없이 유지

- 외부자료 반박이 개별 사업 특수성에 한정됨
- 블라인드 불일치가 한두 사례에 국한됨
- 외부자료가 대부분 근거 부족임
- 모델 질문 문구만 다듬으면 됨

## 진단 문구만 수정

- 등급 자체보다 표현이 과도함
- 집행 또는 보고목표 상태 표현이 사업 특수성을 단정함
- 실제로는 맥락 확인이 필요한 사례임

## 사업특성 태그 후속 필요

- 같은 유형의 반례가 2건 이상 반복됨
- 수요연동형·다년도형·연말집중형·성과시차형 특성이 반복적으로 등급 해석을 바꿈

## 등급 규칙 재검토 필요

- 동일한 원인의 `CONTRADICTED` 사례가 2건 이상임
- D에서 중대한 외부 지적이 반복적으로 발견됨
- A/B보다 C/D를 사람이 반복적으로 먼저 검토함
- H가 공식자료로 쉽게 해소되는 사례가 반복됨
- 특정 신호 제거 시 A↔D 또는 H↔A/B 이동이 반복됨

단일 반례 하나만으로 생산 등급 로직을 수정하지 않습니다. 외부검증과 사람 검토는 별도 증거로 집계하고, 같은 원인의 반복 여부를 확인한 뒤 위 기준을 적용합니다.
