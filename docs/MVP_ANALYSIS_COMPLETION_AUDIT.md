# MVP 분석 완료조건 통합검증

검증일: 2026-07-31

## 결론

수기 성과자료를 사용하는 현재 MVP 범위에서 핵심 엔터티, 교차 품질,
분석별 신뢰도, 동년도·후행 지표, 복수 시나리오 순위와 강건성 검증은
실제 산출물로 확인했습니다.

외부 평가 라벨은 저장소에 없으므로 외부 타당도를 수치로 주장하지 않습니다.
3개 부처 PDF 원문 대조 361행 중 332행은 출처·페이지·원문 근거를 확인했고,
출처나 지표 대응을 사람이 판단해야 하는 29행만 검수 대기로 유지합니다.
이 제한은 완료 산출물에서 숨기지 않습니다.

## 1. 핵심 엔터티와 분석 단위

| 엔터티 | 한 행의 기준 | 행 수 | 핵심 검증 |
|---|---|---:|---|
| 세부사업 재정 v2 | 부처 × 세부사업 × 회계연도 | 9,366 | 기본키 중복 0 |
| 프로그램 재정 | 부처 × 분야 × 부문 × 프로그램 × 회계연도 | 1,008 | 기본키 중복 0 |
| 금액 이벤트 | 원천 레코드 × 금액유형 | 65,162 | 이벤트 ID 중복 0, 고아 사업 ID 0 |
| 월별 집행 | 부처 × 연도 × 월 × 회계 × 프로그램 × 단위사업 × 세부사업 | 101,752 | 원본 대비 행 차이 0, 원천 중복은 별도 플래그 보존 |
| 3개 부처 성과지표 | 부처 × 프로그램 × 성과지표 × 회계연도 | 361 | PDF 대조 입출력 보존, 지표 ID 중복 0 |

금액 이벤트는 여섯 원본 금액유형을 별도 값으로 보존하며 본예산·추경·예산현액을
서로 대체하지 않습니다. 프로그램 집계의 본예산·예산현액·결산 지출액 차이는
모두 0원입니다.

## 2. API·결산·성과자료 교차검증

- 재정 v2는 9,366행이며 세부사업-연도 기본키 중복이 없습니다.
- 프로그램 재정 1,008행 중 `COMPLETE` 511행, `PARTIAL` 1행,
  `UNMATCHED` 496행입니다. `PARTIAL`·`UNMATCHED`의 집행률은 계산하지 않았습니다.
- 3개 부처 성과·재정 결합은 347행이며 339행이 동년도 공동분석 상태입니다.
- 공동분석이 아닌 8행은 재정 연결 제한 4행, 타 부처 재정 프로그램 3행,
  구조적 삭제·이관 1행으로 원인을 보존했습니다.
- M3 신호가 없는 7행과 회계별 금액 불일치 3행은 모두 `DATA_REVIEW`이며
  시나리오 순위에서 제외했습니다.

따라서 불일치가 0이라는 뜻은 아닙니다. 불일치가 최종 후보 순위에 조용히
섞이지 않고 원인별 검수 상태로 분리됐다는 뜻입니다.

## 3. 신뢰도와 수동검토 경계

3개 부처 분석 347행의 현재 분할은 다음과 같습니다.

| 상태 | 행 수 | 사용 범위 |
|---|---:|---|
| 시나리오 순위 적격 | 193 | 네 탐색 시나리오 비교 |
| 데이터 검수 | 14 | 원문·재정 연결 확인 전 순위 제한 |
| 맥락 전용 후보 | 35 | 회계조정·구조 설명 |
| 정보성 | 110 | 후보 순위 밖 구조 확인 |

시나리오 적격 193행은 네 구성요소가 모두 존재합니다. 결측 구성요소를
0점 처리하거나 남은 구성요소로 가중치를 재배분하지 않습니다.

## 4. 동년도·후행 지표

- 동년도 성과·재정 공동분석: 339행
- M3 재정 신호: 6,118 세부사업-연도
- T+1 환류 적격: 2,401행
- T+2 환류 적격: 1,083행

T, T+1, T+2는 별도 모집단과 별도 결과로 유지합니다. 후행 예산변화는
연관 탐색이며 성과나 집행이 예산변화를 일으켰다는 인과결론으로 사용하지 않습니다.

## 5. 복수 순위와 강건성

균등가중, 성과중심, 집행중심, 재정영향 보정의 네 시나리오를 보존했습니다.

- 순위 적격: 193행
- 시나리오 간 Spearman: 0.646~0.917
- 순위범위 중앙값: 45
- 순위범위 최댓값: 124
- 모든 시나리오 공통 Top 5: 0건
- 모든 시나리오 공통 Top 10: 0건

최신 6,118행으로 M3 방법론 감사를 다시 실행했습니다. 프로그램-연도 키,
프로젝트 반복 키, 동률 처리, T+1·T+2 분리, 사업 단위 군집 부트스트랩,
선행 0 부처코드 보존 검증이 모두 통과했습니다.

공통 상위 후보가 없으므로 특정 가중치나 평균순위를 최종 정책 우선순위로
채택하지 않습니다. 외부 평가자료가 없으므로 외부 타당도는
`NOT_ASSESSABLE_NO_EXTERNAL_REFERENCE`로 기록합니다.
